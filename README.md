# 📚 Plataforma Cloud para Exploración de Archivos en Humanidades Digitales basada en Grafos de Conocimiento
 
> Proyecto de Titulación — Departamento de Ciencias de la Computación (DCC)  
> En colaboración con el **Instituto Milenio Fundamentos de los Datos (IMFD)**
 
---
 
## 🧭 Descripción General
 
Este proyecto consiste en el diseño e implementación de una **plataforma cloud** que permite a investigadores de Humanidades Digitales cargar, procesar y explorar colecciones documentales históricas de forma automatizada.
 
La plataforma transforma documentos en formato PDF o imágenes escaneadas en **grafos de conocimiento navegables**, facilitando el descubrimiento de relaciones entre entidades, eventos y documentos históricos que de otro modo requerirían análisis manual extenso.
 
---
 
## ✨ Funcionalidades Principales
 
- **Carga de documentos**: Soporte para PDFs e imágenes escaneadas.
- **OCR automatizado**: Extracción de texto desde documentos digitalizados.
- **Extracción de conocimiento**: Identificación automática de entidades y relaciones mediante NLP.
- **Grafos de conocimiento**: Construcción y almacenamiento de grafos usando Wukong y MillenniumDB.
- **Exploración visual**: Interfaz gráfica para navegar el grafo de conocimiento generado.
- **Chatbot semántico**: Interfaz conversacional para realizar consultas sobre los documentos procesados.
 
---
 
## 🔬 Desafíos Técnicos
 
### Inteligencia Artificial
- Extracción robusta de entidades y relaciones desde documentos heterogéneos y ruidosos.
- Resolución de entidades y construcción consistente de grafos desde múltiples fuentes.
- Interfaz conversacional con comprensión semántica sobre el corpus procesado.
 
### Ingeniería de Sistemas
- Integración de componentes complejos: OCR, pipelines NLP, base de datos de grafos y servicios conversacionales.
- Arquitectura modular que permita reemplazar componentes sin afectar el sistema global.
 
### Computación
- Procesamiento distribuido de documentos en infraestructura cloud.
- Consultas eficientes sobre grafos potencialmente grandes con tiempos de respuesta interactivos.
